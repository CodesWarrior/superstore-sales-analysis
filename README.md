# superstore-sales-analysis
Excel Sales Dashboard Project using Power Query and Pivot Tables
End-to-end sales analysis on 9,994 row Superstore dataset

## Tools Used
- Excel Power Query
- Pivot Tables
- Dynamic KPI Cards
- Interactive Slicers

## Key Findings
- West region leads in sales and profit
- Furniture has high sales but lowest profit margin
- Extreme discounting causes -₱76,559 in losses
- 18.72% of all transactions are loss-making
